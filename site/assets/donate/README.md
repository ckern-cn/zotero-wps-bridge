# 捐赠二维码

这里的二维码是**公开的收款码**，会随官网和插件一起分发：

- `alipay-qr.png`：支付宝
- `wechat-qr.png`：微信支付

它们不是密钥或隐私数据，但注意：

- 公开仓库中的任何人、任何 fork 都可以看到并扫描这些二维码。
- 如果你 fork 了这个项目，请替换成自己的收款码，或移除捐赠入口；不要使用原项目的收款码收取捐赠。
- 更换收款码后，请同时替换插件内的 `src/wps-addon/images/donate-*.png` 和 `src/zotero-plugin/content/donate/*.png`。
- 原始手机截图放在本地 `pay/`，不要提交到仓库。
