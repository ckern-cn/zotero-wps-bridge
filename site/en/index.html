Chapter 3 · Literature review

Managing sources in digital humanities

Open science and reproducible research have become central to academic writing(Zhang, 2024). Researchers increasingly embed citation tools into their writing workflow to avoid manual bibliography errors(Li et al., 2023).

In Chinese office environments, WPS Writer remains the default for many universities and institutions. Bringing Zotero into WPS lets researchers keep a familiar workflow while using the same library.

Features

What you will actually use

Not another Zotero client—just Zotero's citation engine, connected to WPS Writer.

Insert / edit citations

Add a citation at the cursor, or click an existing one to edit items, locators, prefixes, and suffixes.

Automatic bibliography

Generate a bibliography at the end of the document, sorted by the active CSL style and updated on refresh.

Document preferences

Switch citation style, language, and body / footnote / endnote placement without rebuilding the document.

One-click refresh

When item metadata changes, refresh the whole document and keep citations and bibliography in sync.

Notes and annotations

Insert Zotero notes, annotations, or highlights as citations while preserving basic formatting and punctuation.

Unlink and export

Keep the rendered text and remove field codes when finalizing, or export to another word processor.

Install

Three steps, about 3 minutes

Install the Zotero plugin first, then ask Zotero to write the add-in into WPS. Restart WPS after every update.

01

Install the Zotero plugin

Download the XPI, install it from Tools → Plugins in Zotero, then restart Zotero.

Download the latest XPI →
02

Install the WPS add-in

Open Zotero Settings → WPS, click “Install / Repair WPS Add-in”, then fully quit and restart WPS Writer.

If no directory is found, start WPS once, then refresh the status.
03

Start citing

In WPS Writer, open the Zotero tab and click “Add/Edit Citation”, then choose an item.

Troubleshooting →
First run: if there is no Zotero tab in WPS, start WPS once so it creates the jsaddons directory, then return to Zotero Settings and click “Install / Repair WPS Add-in”.

FAQ

Common installation and usage questions

There is no Zotero tab in WPS.

Start WPS once (you can close it immediately) so it creates the jsaddons directory. In Zotero Settings → WPS, click “Refresh Status”, then “Install / Repair WPS Add-in”. Fully quit WPS, including tray or background processes, and open it again.

It says it cannot connect to Zotero.

Make sure Zotero is running, the Zotero WPS Bridge plugin is enabled, and port 23119 is available. Use “Check Connection” in WPS or inspect the port and token in Zotero Settings → WPS. Your firewall must allow local loopback connections.

Why must I restart WPS after installing or updating?

WPS caches files in the add-in directory. Closing document windows may not release the background process. Fully quit WPS Writer and launch it again.

Are my documents uploaded anywhere?

No. The WPS add-in talks to Zotero over 127.0.0.1 only. There is no account system, cloud sync, or telemetry; citations and documents are processed locally.

Is it compatible with Zotero's Word plugin?

It uses Word-compatible ADDIN ZOTERO_* fields, so the same .docx can be edited in Word and WPS. Complex styles, merged citations, and round trips should still be tested on a copy.

Which Zotero and WPS versions are supported?

Zotero 7.0–10.9.9 and WPS Writer 12.x. Linux has been verified with WPS 12.1.2 and Zotero 10.0.8; Windows and macOS remain beta.

How do I uninstall it?

In Zotero Settings → WPS, click “Uninstall WPS Add-in”, then restart WPS. Existing citations in documents are not deleted.
